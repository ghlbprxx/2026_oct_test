# Decisions (one line each: decision — reason)

- 2026-11-01 Root Walk This Way project moved to `walk-this-way/` — matches the folder name another session already used on branch claude/calm-ui-story-mode-r6qdgz, so the repos converge.
- 2026-11-01 ES modules + import map (Vue `vue.esm-browser.prod.js` from jsDelivr, pinned 3.4.21) — brief requires ES modules; jsDelivr serves the npm dist file verbatim. Requires a local server; file:// shows a message.
- 2026-11-01 `CONFIG_SCHEMA` lives in `js/config-schema.js` (pure data), re-exported by `js/config.js` (ISF panel, template verbatim) — node tests can build default config without the DOM-bound panel.
- 2026-11-01 Sim modules take state + config via `sim/cfg.js` (`setConfig`) and randomness via `sim/rng.js` (`setRng`) — keeps `sim/` pure and seedable for tests; the app injects the reactive CONFIG.
- 2026-11-01 Sim → UI communication through an event bus (`sim/events.js`) — sim never touches DOM/Vue/audio; the UI maps events to toasts, SFX, floats, modals, ISF metrics.
- 2026-11-01 Added `sim/game.js` (newGame, update, player actions) beyond the brief's file list — needs a home for orchestration that isn't one subsystem.
- 2026-11-01 Embedded manifest copy + tools/sync-manifest.mjs removed — brief: fetch assets/images.json; on failure use SVG placeholders. ES modules already require a server, so the file:// reason for the copy is gone.
- 2026-11-01 Testing in this sandbox routes the jsDelivr Vue URL to the identical npm tarball file — the sandbox blocks CDNs; shipped code still uses the CDN.
- 2026-11-01 package.json test script is `node --test "tests/*.test.js"`, not `node --test tests/` — Node 22 treats positional args as files/globs and fails on a bare directory; the quoted glob is expanded by Node itself (works on Windows too) and skips tests/helpers.js.
- 2026-11-01 Species biology (durations in real days, per-day hazards, yields, consumable prices) lives in `js/content/species/*.js`; the admin panel exposes ~30 cross-cutting knobs (scales, economy, difficulty) — resolves the brief's "all numbers as knobs" vs "20–30 knobs"; data files stay hand-editable.
- 2026-11-01 Time model: biology (growth, contamination, shelf life, cooker cycle) runs in bio days = game days × time.bioDaysPerGameDay; calendar things (weeks, market days, cold snaps, season) run in game days.
- 2026-11-01 Display units are lb and $/lb (US audience, matches researched prices); internal yields stay kg.
- 2026-11-01 Phase 2 slow start gates systems by week (plates → jars → bags → grow room, every progression.unlockPace weeks). Interim: Phase 4 replaces it with mastery.
- 2026-11-01 Still-air box is a one-time $15 DIY build offered in the build menu (cleanliness = the week-1 variable); Phase 3 folds it into the equipment shop.
- 2026-11-01 Relaxed "soft contamination" = mold on jars/bags can be cut out (keeps difficulty.salvageQuality of yield/uses) instead of tossing.
- 2026-11-01 (user add-on) Images stay optional: assets/tools/gen-images.mjs runs a user-filled command template from assets/tools/image.config.json per missing file; it never guesses fal.ai CLI flags, mirrors the brief's gen-voice.mjs design.
- 2026-11-01 GSAP 3.12.5 via import map ("gsap" → jsDelivr index.js, ESM), loaded with dynamic import() in fx.js so a CDN failure only drops animations; moves across zones animate a fixed-position clone because zones clip overflow.
- 2026-11-01 Season rank uses operating profit (cash change + gear bought); gear is equipment the player keeps — careful-bot season: ~$300 revenue vs ~$430 of gear, so cash profit punished good play. Phase 4 (shop sales of mastered stages) is where the money loop is meant to close.
- 2026-11-01 Admin metrics: the verbatim ISF panel only aggregates `runEnd` data, so each weekly review logs a runEnd row with kind:"week" (stage, mastered, net, clean rate, revenue by product, weeks repeated, reputation); deaths keep losses by cause.
- 2026-11-01 Admin help (user request): js/config-help.js holds what/min/default/max per knob; js/admin-help.js adds a <details> under each row of the ISF panel through its open shadow root, so the panel template itself stays verbatim. Rows match schema order.
- 2026-11-01 Headless playtesting lives in js/sim/autoplay.js (pure, reuses the real sim actions) + tools/playtest.mjs (table) + tests/economy.test.js (assertions) — replaces tests/bot.test.js.
- 2026-11-01 Money fix via a real purchase, not inflated prices: wire shelf rack (+3 closet spots, $60). Without it, 7 incubation spots couldn't feed both the ladder and online sales.
- 2026-11-01 Market booking is a sim option (marketMode auto/book/skip); 'auto' books only when the haul is worth 3× the booth fee. Basic play uses auto; Advanced can choose.
- 2026-11-01 Play style (Basic/Advanced) is UI-only and stored in the profile; the sim is identical, so economy proofs hold for both. Basic hides the ISF panel host; Advanced shows it with an essentials filter (admin-help.js), panel template still verbatim.
- 2026-11-01 Phase 5: run type (tutorial/story/free/expert) is stored on the run as `g.runType`, but the sim never reads it; scenes come from `js/director.js` reacting to sim events in main.js. Economy proofs therefore cover every mode.
- 2026-11-01 The only sim change for story is one new event, `forecast` (cold snap tomorrow), so the mentor can warn before it hits. It uses no randomness, so seeded runs are unchanged.
- 2026-11-01 The guru always claims the statement is true; he is right exactly when it's a fact (6 of 13 myths ≈ 46%), which matches the brief's "confidently wrong about half the time" with no extra data. The quiz reward ($3 tip) and timing are unchanged.
- 2026-11-01 Week-intro cards (content/weeks.js) stay as practical bullet cards after the story scene instead of becoming voiced mentor lines: they're instructions, not dialogue, and they also serve free play.
- 2026-11-01 "Week 0 tutorial ends by unlocking week 1" is implemented as "the tutorial ends and the clock starts in week 0 (agar)": the ladder already starts at week 0, and adding a pre-week would shift every economy test.
- 2026-11-01 Expert has no new content until Phase 6 (liquid culture); it currently means free play without the Next: coaching line. Unlocks automatically on the first species win (profile.expert).
- 2026-11-01 Run save bumped to v3 (runType, story.seen); v2 saves migrate to free play.
- 2026-11-01 Phase 6: species data is looked up per vessel (v.sp) and per harvest lot (l.sp), not per game, so vessels from an earlier species finish with their own biology, price and shelf life. Anything without a species is pink oyster, which kept the pink playtest table byte-identical through the refactor (the regression check used at every step).
- 2026-11-01 The pink knobs (economy.priceFresh, shelfLife) stay the base; other species are multipliers in their content file (priceMult, shelfMult). Dried product is priced with the current species' multiplier (approximation: g.dried is one pool).
- 2026-11-01 Species are sequential (mastery card button, startSpecies); stages repeat per species, and stages already mastered on an earlier species need half the units (RULES.transferUnits = 0.5): "learned lessons shorten later species".
- 2026-11-01 Stage openings moved from fixed indices (OPENS) to stage ids (OPENS_BY/opensIndex) so ladders can differ (wine cap's spawn/bed, Expert's inserted LC stage). Identical results for the old ladders (tested).
- 2026-11-01 Wine cap uses the fast end of real bed timing (chips ~70 real days, straw ~45) so a bed fruits within a few in-game weeks; real beds often take 2–6 months.
- 2026-11-01 Mastery-unit choices that avoid deadlocks found by the headless player: wine cap bed = moist colonizing bed-days (not "beds inoculated": 2 yard spots, beds last years); Expert LC = grain jars seeded from dilute LC (not "LCs colonized": one LC has 6 uses).
- 2026-11-01 Expert runs keep the story cast (Phase 5 had them script-free) so the LC scene plays; Free play is the script-free mode.
- 2026-11-01 Automation is per stage mastered on the CURRENT species (pauses when you start a new one, so it can't skip learning). Fees ($2–5/week each, $20 for all six minus beds) are tuned so a fully automated pink farm roughly breaks even: it buys attention, not profit.
- 2026-11-01 Until species art exists (Phase 7), lion's mane and wine cap reuse the pink cluster art with a CSS filter (.slot.sp-*); new placeholder art: bed, lc_jar, lc_growth (+ images.json entries).
